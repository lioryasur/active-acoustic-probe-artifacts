# Artifact Scope

This repository is a camera-ready artifact bundle. It is designed to make the
probe definition and detector implementation inspectable and runnable without
publishing the full exploratory research workspace.

Included:

- frozen probe and detector configuration;
- probe generation code;
- peak-to-sideband scoring code;
- scripts for scoring external WAV files;
- a minimal browser acoustic-loop test.

Not included:

- raw participant/device recordings;
- converted provider outputs;
- generated CSV result tables;
- exploratory tuning scripts;
- local machine paths and recording logs.

The companion browser proof-of-concept repository demonstrates the networked
browser/WebRTC probe path.
